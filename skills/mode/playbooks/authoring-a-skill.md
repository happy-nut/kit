# 스킬 쓰기·고치기

**스킬의 목소리를 소유한다.**

1. `skill-creator` 스킬로 SKILL.md 를 쓴다.
2. 스킬을 검사한다. frontmatter 에 `name` 과 `description` 이 있고, 가리키는 파일이 있고, 다른 스킬 링크가 풀린다.
3. 구조적인 스킬이면 시험을 만든다. 주관적이면 생략한다.
4. `opening-a-pr.md` 를 따른다.

헷갈리면 지운다. 결정을 바꾸는 글만 남긴다. 할 일을 말하고 이유는 뺀다. 이유가 없으면 헷갈리는 규칙에만 설명을 붙인다. 어조는 범위에 맞춘다. principles.md 의 Encode Lessons in Structure 대로 구조적 정본(타입, README, 설정)을 가리킨다. 다른 스킬에는 경로로 넘긴다. 되풀이하지 않는다. 자꾸 부딪치는데 담긴 곳이 없는 작업 흐름이 있으면 새 스킬을 제안한다.

**답:** 스킬 요약, 핵심 설계 결정, 검사 메모.
