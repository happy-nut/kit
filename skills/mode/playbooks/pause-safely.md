# 안전하게 멈추기

**깔끔한 멈춤을 소유한다. 처음부터 시작하는 에이전트가 이어 갈 수 있는 체크포인트를 남긴다.** 명시적일 때만 한다. 「계속해」, 「자러 간다, 계속해」, 「멈추지 마」에는 멈추지 않는다.

1. 안전한 경계에서 멈춘다. 지금 하던 원자적 단계를 끝내거나 물린다. 새로 시작하지 않고, 안에서 돌고 있는 서브에이전트를 모두 멈춘다.
2. 멈추려고 되돌릴 수 없는 행동을 하지 않는다. 이미 내놓은 것이 없으면 PR 도 push 도 하지 않는다.
3. 일을 디스크에 남긴다. 커밋 안 한 편집을 지금 브랜치에 분명한 `wip:` 커밋 하나로 남겨 잃는 것이 없게 한다. 트리가 깨져 있으면 커밋 본문에 한 줄로 적는다.
4. 맥락 밖에 재개 노트를 쓴다. 의도, 무엇을 하고 있었는지, 진행과 검증된 것, 지금 상태, 다음 단계, 핵심 파일, 함정을 담는다. 맥락 압축 때문에 멈추면 `/tmp/<slug>-resume.md` 같은 파일에 쓴다. `/dev:log` 기록이 있으면 되풀이하지 말고 그것을 가리킨다.

**답:** 루프의 어디에 있는지, 디스크에 있는 것과 아직 머릿속에만 있는 것(경로만, diff 덤프 없이), 만든 커밋과 트리가 깨끗한지, 재개할 때의 첫 행동. 멈춤이지 최종 보고가 아니다.
