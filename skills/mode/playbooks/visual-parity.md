# 시각 동등성

**픽셀 단위 동등성을 소유한다. 기준선이 명세다. 기준선은 건드리지 않는다.** 동등성은 눈이 아니라 이미지 diff 로 검증한다.

1. 이전을 시작하기 전에 기준선부터 만든다. 지금 컴포넌트를 상태별로 스크린샷하는 시각 회귀 하네스를 만들고, 두 구현을 맞추는 일이면 목표 쪽도 찍는다. 기준선이 없으면 동등하다고 말하지 않는다. 후속이 아니라 먼저 막는 선행 조건이다.
2. 지름길 금지 조항을 적고 지킨다. 하네스 수정 금지, 기준선 조작 금지, diff 를 통과시키려는 컴포넌트 재구성 금지. 기준선이 이상해 보이면 멈추고 묻는다. 고치지 않는다.
3. 한 번에 컴포넌트 하나씩 옮긴다. 워크트리를 나눠 병렬로 돌리고 컴포넌트마다 owner 하나를 둔다(principles.md 의 Separate Before Serializing Shared State). 공유 프리미티브는 먼저 막는 단계로 가장 먼저 옮긴다.
4. 컴포넌트마다 맞는 표면에서 `/dev:control-ui` 로 기준선과 이미지 diff 를 해 검증한다. diff 가 0 이 아니면 실패다. 픽셀 차이를 조사한다. 컴포넌트마다 diff 가 0 이 될 때까지 Claude Code `/loop` 스킬로 돈다.
5. 컴포넌트마다, 또는 안전한 묶음마다 `opening-a-pr.md` 를 따른다.
