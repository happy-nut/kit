# 운영 플랫폼 통합 기획서

- 작성: 운영기획팀
- 작성일: 2026년 10월 14일
- 검토 요청: 운영본부장

## 1. 배경과 문제

지금 운영 업무는 세 도구로 나뉘어 있다.

| 도구 | 하는 일 | 만든 방식 | 쓰는 사람 |
|---|---|---|---|
| 정산 어드민 | 가맹점별 정산 금액 확인, 지급 보류와 해제 | 2019년 자체 개발 | 재무운영팀 22명 |
| CS 툴 | 문의 접수와 답변, 환불 요청 처리 | 외부 SaaS | 고객센터 60명 |
| 가맹점 관리 | 계약 정보, 수수료율, 서류 심사 | 2021년 자체 개발 | 영업지원팀 15명 |

세 도구는 가맹점을 찾는 기준이 다르다. 정산 어드민은 사업자등록번호로, 가맹점 관리는 내부 가맹점 코드로, CS 툴은 문의자 이메일로 가맹점을 찾는다. 그래서 상담원은 가맹점 문의 하나를 처리하려고 세 도구를 오가며 같은 가맹점을 세 번 찾는다.

문제는 셋이다.

1. 처리 시간이 길다. 지난 분기 가맹점 문의 1건의 평균 처리 시간은 18분이다.
2. 데이터가 어긋난다. 수수료율을 가맹점 관리와 정산 어드민에 따로 입력해서, 두 도구의 수수료율이 다르게 기록된 가맹점이 있다.
3. 유지 비용이 든다. 자체 개발 도구 둘을 개발자 2명씩, 모두 4명이 따로 유지한다. CS 툴 라이선스는 연 1억 2천만 원이다.

## 2. 제안

세 도구를 하나의 「운영 플랫폼」으로 합친다. 가맹점 하나를 열면 계약, 정산, 문의 이력이 한 화면에 보인다.

- 가맹점 기준을 내부 가맹점 코드 하나로 통일한다.
- CS 툴은 해지하고 문의 기능을 새로 만든다.
- 권한은 역할별로 나눈다.

## 3. 기대 효과

- 가맹점 문의 평균 처리 시간을 18분에서 7분으로 줄인다. (근거: 파일럿 상담원 3명이 시제품 화면으로 처리한 문의 40건의 평균이 7분이었다.)
- 수수료율 불일치를 없앤다. (근거: 원천 데이터가 하나가 되므로.)
- 연간 운영비를 약 1억 원 줄인다. (근거: CS 툴 라이선스 1억 2천만 원이 빠진다. 새 플랫폼 유지 인력은 4명에서 3명으로 준다.)
- 상담원 만족도가 오른다. (근거: 파일럿 참여자 3명 모두 「훨씬 편하다」고 답했다.)

## 4. 가정

- 세 도구의 가맹점 데이터를 내부 가맹점 코드로 이어 붙일 수 있다. 사업자등록번호 하나에 내부 코드가 여럿인 가맹점은 아직 세지 않았다.
- 새 문의 기능이 지금 CS 툴에서 실제로 쓰는 기능을 모두 대신한다.
- 이전 기간에는 세 도구와 새 플랫폼을 함께 돌린다.

## 5. 대안 검토

- 현행 유지: 문제가 계속되므로 제외한다.
- 세 도구는 그대로 두고 서로 연동만 하기: 화면이 여전히 셋이라 효과가 작다고 판단해 제외한다.

## 6. 일정과 자원

- 1단계 (2027년 1~3월): 가맹점 기준 통일, 데이터 이전
- 2단계 (2027년 4~6월): 정산 화면과 가맹점 화면 통합
- 3단계 (2027년 7~9월): 문의 기능 개발, CS 툴 해지
- 인력: 개발 5명, 기획 1명, 디자인 1명. 9개월.

## 7. 요청 사항

- 1단계 착수 승인
- 개발 인력 5명 배정
